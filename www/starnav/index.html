StarNav Monitor

Starlink → MAVLink Position Forwarding

StarNav Documentation

Overview

StarNav reads position data from a Starlink dish via gRPC and forwards it to an ArduPilot flight controller as MAVLink external position (EXTPOS) messages. This enables GPS-denied navigation using Starlink's built-in positioning capability as an alternative or supplementary position source for the EKF.

ArduPilot Parameter Setup

Set the following parameters on your flight controller for StarNav external position fusion:

ParameterValueDescription
EK3_SRC2_POSXY8External Position for source set 2 horizontal position
EK3_SRC2_POSZ8External Position for source set 2 vertical position
EK3_SRC2_VELXY0None (StarNav does not send velocity)
EK3_SRC2_VELZ0None (StarNav does not send velocity)
EK3_SRC2_YAW0None (no yaw from StarNav)
EK3_EXTPOS_GATE500Innovation gate for external position (generous for Starlink noise)
RC_OPTION (spare)90EKF source set switching on an RC channel (optional)

Source set 1 should remain configured for GPS as your primary source. Use RC channel switching or autonomous logic to switch to source set 2 (StarNav) when needed.

Troubleshooting

  • Status shows "Stopped": Click Start, or check that starnav service is installed. Run systemctl status starnav on the companion.
  • No Starlink position data: Verify the dish is powered and reachable at the configured DISH_ADDRESS. Try ping 192.168.100.1.
  • Uncertainty too high / not sending: Starlink position accuracy varies. Ensure clear sky view. Increase UNCERTAINTY_LIMIT if needed.
  • EKF not accepting positions: Check that EK3_SRC2_POSXY=8 and you have switched to source set 2. Verify EK3_EXTPOS_GATE is set high enough (500 recommended).
  • MAVLink connection failed: Confirm the MAVLink endpoint is correct and the autopilot is reachable. Check firewall rules and serial port permissions.
  • Log stream disconnects frequently: This can happen if the companion CPU is overloaded or the network is intermittent. The UI will auto-reconnect.
  • Update fails: SSH into the companion and run cd /opt/starnav && bash install.sh manually to see detailed errors.
